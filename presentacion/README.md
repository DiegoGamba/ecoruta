# Presentación del proyecto

| Archivo | Uso |
|---|---|
| `EcoRuta-presentacion.pdf` | Versión para leer y proyectar |
| `EcoRuta-presentacion.pptx` | Versión editable, con notas del expositor |
| `build_deck.js` | Script que genera el archivo (`node build_deck.js`) |

Catorce diapositivas: problema, delimitación y objetivos, solución, arquitectura,
justificación tecnológica, modelo de datos, algoritmo de agrupamiento, seguridad,
calidad de ingeniería, costos, proyección investigativa, entregables y cierre.
